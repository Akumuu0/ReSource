# \# ReSource

# 

# \*\*Intelligent, AI-Powered Circular Campus Resource Exchange and Asset Life Cycle Management System\*\*

# 

# COSC 336 · Group 3

# 

# ReSource lets campus departments share assets they no longer need instead of buying new ones or throwing them away. A department registers and publishes an asset, another department requests it, and after approval the asset is transferred. Every step is tracked, and a dashboard shows the money, waste and carbon saved.

# 

# \## Main features

# 

# \- \*\*Login and roles:\*\* Department Representative, Asset Coordinator and Administrator

# \- \*\*Assets:\*\* register, publish, search, and a full history of every change

# \- \*\*Requests:\*\* submit, approve, transfer and confirm receipt, with notifications at each step

# \- \*\*Sustainability dashboard:\*\* money, waste and carbon saved, plus a request report with CSV export

# \- \*\*AI support:\*\* suggests an asset's category, ranks the best matches for a need, and writes sustainability summaries
